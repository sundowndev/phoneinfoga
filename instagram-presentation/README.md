# 📱 Instagram 3D Presentation - عرض تقديمي ثلاثي الأبعاد عن إنستجرام

عرض تقديمي تفاعلي وثلاثي الأبعاد عن تطبيق إنستجرام، يتضمن المميزات والإيجابيات والسلبيات.

## ✨ المميزات

- 🎨 تصميم ثلاثي الأبعاد تفاعلي باستخدام Three.js
- 🌈 ألوان إنستجرام الرسمية (Instagram Gradient)
- 📱 واجهة عصرية وجذابة
- 🔄 انتقالات سلسة بين الشرائح
- 📊 معلومات شاملة عن إنستجرام
- 🎯 محتوى باللغة العربية
- 💫 تأثيرات بصرية مذهلة
- 📱 متجاوب مع جميع الشاشات

## 📋 محتوى العرض التقديمي

1. **شريحة العنوان** - مقدمة جذابة
2. **ما هو إنستجرام؟** - تعريف ومعلومات أساسية
3. **المميزات الرئيسية** - 3 شرائح تغطي جميع المميزات
4. **مميزات إضافية** - فلاتر، هاشتاجات، وأكثر
5. **الإيجابيات** - 8 نقاط إيجابية
6. **السلبيات** - 8 نقاط سلبية
7. **إحصائيات** - أرقام مذهلة عن إنستجرام
8. **نصائح للنجاح** - 6 نصائح عملية
9. **الخلاصة** - ملخص شامل
10. **شريحة الشكر** - نهاية احترافية

## 🚀 كيفية الاستخدام

### الطريقة الأولى: فتح الملف مباشرة

1. افتح ملف `index.html` في متصفح الويب
2. استخدم الأسهم أو المسافة للتنقل بين الشرائح

### الطريقة الثانية: استخدام خادم محلي

```bash
# استخدام Python 3
cd instagram-presentation
python3 -m http.server 8000

# أو استخدام Node.js
npx http-server

# ثم افتح المتصفح على
http://localhost:8000
```

## ⌨️ مفاتيح التحكم

| المفتاح | الوظيفة |
|---------|---------|
| `→` أو `Space` | الشريحة التالية |
| `←` | الشريحة السابقة |
| `ESC` أو `O` | نظرة عامة على جميع الشرائح |
| `F` | وضع ملء الشاشة |
| `S` | عرض ملاحظات المتحدث |
| `H` | مساعدة |
| `?` | إظهار جميع المفاتيح |

## 📝 التخصيص

### تغيير الألوان
عدل متغيرات CSS في ملف `style.css`:

```css
/* ألوان إنستجرام */
--instagram-blue: #405DE6;
--instagram-purple: #833AB4;
--instagram-pink: #C13584;
--instagram-orange: #FD1D1D;
```

### إضافة شرائح جديدة
أضف شريحة جديدة في ملف `index.html`:

```html
<section data-background-color="#833AB4">
    <h2 class="section-title">عنوان الشريحة</h2>
    <div class="content-box">
        <!-- المحتوى هنا -->
    </div>
</section>
```

### تغيير الانتقالات
في ملف `script.js`، غير قيمة `transition`:

```javascript
Reveal.initialize({
    transition: 'slide', // none/fade/slide/convex/concave/zoom/cube
});
```
